PIXEL ARENA - 3-PAGE HTML/CSS ASSIGNMENT

FILES
- index.html       Home page
- games.html       Featured games page
- gallery.html     Gallery page (6 images)
- css/style.css    Shared stylesheet
- images/          Original SVG illustrations used by the pages

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. Use the navigation links to open Games and Gallery.

ASSIGNMENT REQUIREMENTS INCLUDED
1. Three original HTML pages; each page contains images. Gallery has six images.
2. Semantic HTML structure and page titles are included.
3. Skip to Main Content link uses position:absolute and :focus; it is off-screen until focused.
4. Navigation uses multiple CSS properties and Flexbox.
5. Images use border, padding, and border-radius through the img rule.
6. CSS Grid is used for feature cards, game cards, and gallery cards.
7. Flexbox is used for navigation, metadata, and footer layout.
8. Hover effects are included on navigation links, buttons, and cards.
9. :nth-child() alternates the image frame shape in the gallery.
10. Images have descriptive alt text; landmarks and headings are used.

VALIDATION BEFORE SUBMISSION
- HTML: https://validator.w3.org/  (validate index.html, games.html, and gallery.html separately)
- CSS: https://jigsaw.w3.org/css-validator/ (optional but recommended)
- Accessibility: https://wave.webaim.org/ (check all three pages after hosting, or test locally if the tool accepts the page)
